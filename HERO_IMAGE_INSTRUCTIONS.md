# Hero Background Image Instructions

## Current Issue
The current hero-background.jpeg shows a soccer stadium, which is incorrect for our NFL picks app.

## Recommended NFL Images Sources

### Free Sources (Unsplash)
1. **Search Terms:**
   - "american football stadium crowd"
   - "nfl fans cheering beer"
   - "football stadium sunset golden hour"
   - "american football celebration"

2. **Specific Recommended Photos:**
   - Thomas Park's NFL stadium crowd photos
   - Dave Adamson's football stadium sunset shots
   - Jeffrey F Lin's American football stadium images

### Premium Sources
1. **Shutterstock** - Search: "NFL stadium crowd celebration golden hour"
2. **Getty Images** - Search: "American football fans beer toast stadium"

## Image Requirements
- **Resolution:** Minimum 1920x1080, prefer 2560x1440
- **Format:** JPEG or WebP for best performance
- **Aspect Ratio:** Landscape (16:9 or wider)
- **Lighting:** Golden hour or warm stadium lights
- **Content:** NFL stadium with celebrating fans (ideally with drinks/toasting)
- **File Size:** Under 1MB when optimized

## To Replace Current Image
1. Download your chosen NFL stadium image
2. Optimize it (compress to under 1MB)
3. Rename it to `hero-background.jpeg`
4. Replace the file at: `/public/images/hero-background.jpeg`

## Alternative: CSS-Only Background
If you prefer not to use a photo, the app now includes `NFLHeroBackground.tsx` component with:
- Animated gradient backgrounds
- Football field pattern overlay
- Stadium lights effects
- Goal post silhouettes
- Football emoji decorations

To switch to the CSS-only version, the home page is already updated to use `NFLHeroBackground` component.
