# NFL Pick'em League Application

## Project Purpose
This is an NFL Pick'em League application designed for managing pick'em leagues where users can make weekly game predictions, track scores, and compete in leagues. The app features a modern, ocean-to-sunset themed UI with glass morphism effects.

## Tech Stack
- **React 19** with TypeScript for the UI layer
- **Vite** as the build tool and development server
- **Tailwind CSS v4** with @tailwindcss/vite plugin for styling
- **TanStack Router** for type-safe routing with code splitting
- **TypeScript** with strict mode enabled
- **ESLint** for code quality and linting

## Planned Backend Integration
- Laravel backend API hosted on Digital Ocean
- Laravel Sanctum for authentication
- ESPN API data synchronization for game schedules and scores

## Design System
Custom ocean-to-sunset color palette:
- Midnight Navy (#062440)
- Ocean Blue (#005A7C) 
- Sky Blue (#4DA6D9)
- Sunset Orange (#FF6B35)
- Sunrise Gold (#FFB935)

Components use glass morphism effects and follow atomic design principles.
