# Development Commands

## Core Development Commands
- `npm run dev` - Start the Vite development server with hot module replacement (HMR)
- `npm run build` - Run TypeScript compiler then create production build with Vite
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint to check code quality

## Package Management
- `npm install` - Install all dependencies
- `npm install <package>` - Install a new package
- `npm update` - Update packages to latest versions

## System Commands (Darwin/macOS)
- `git` - Version control (available at /usr/bin/git)
- `ls` - List directory contents
- `cd` - Change directory
- `grep` or `rg` (ripgrep) - Search files for patterns
- `find` - Find files and directories

## Testing
No testing framework is currently configured. When tests are added, consider using Vitest which integrates well with Vite.

## Important Notes
- No test commands are currently available
- The project is not yet connected to a git repository
- Use npm for package management (not yarn or pnpm)
